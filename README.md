# boondock-echo-demo

Live radio transcription demo in the root [`index.html`](index.html), plus a manual-PTT Morse and voice companion.

## Morse Radio

[morse-radio/](morse-radio/) is a static page (no build, no API keys) for sending and receiving Morse, pictures, and voice over a radio you key by hand.

On GitHub Pages it is served next to this demo, for example `https://<user>.github.io/boondock-echo-demo/morse-radio/`.

Wiring, the PIXM1 picture protocol, and how to turn on Pages are in [morse-radio/README.md](morse-radio/README.md).
