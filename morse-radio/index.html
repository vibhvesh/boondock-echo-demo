PIXM1 PROTOCOL

On-air text is PIXM1 WW HH, then one word per row of W/B runs, then C plus a 6-digit checksum, then END. Width and height are two digits (08, 16). Spaces can be stripped. O is read as 0 and I as 1 inside numbers. Paste the decoded letters on Receive to rebuild the picture. Full write-up is in the README.

Voices come from this device. Hindi and English are listed first when the system has them.

Spoken with the browser’s built-in speechSynthesis. No cloud voice. The same PTT countdown runs before the words.

Speed hint is the character speed. Farnsworth text is slower than this.

Listen with the radio’s speaker near this mic, or a padded cable into the mic jack. Set the tone in CW TX to the pitch you will hear. The sidetone check runs the last transmission through the same decoder, with no second radio.

Whisper (transformers.js) downloads once from the public CDN, then runs in this browser. No key. Squelch waits for voice the way the Echo demo does. Web Speech is the fallback and may use your browser vendor’s recognizer.

⚙ SETTINGS
Wiring. Patch the device headphone jack into the radio mic or line input. A mic input is hot — a series resistor (about 1 kΩ) keeps it from overdriving. Set volume so the radio moves but does not flat-top. When the screen says PRESS PTT NOW, hold the radio PTT through ON AIR, then release. To receive, put the radio speaker by this mic, or a padded speaker-out into the mic jack. Match the CW tone to the pitch you hear. Nothing here keys the radio for you.
Clips, pictures, and settings stay in this browser (IndexedDB and localStorage). Whisper weights cache in the browser after the first download. No account, no API key.
